## 2. Как сайт попадает в интернет

```
правка в GitHub  →  сервер каждые 5 минут делает git pull  →  nginx отдаёт папку public/
```

- Сайт — это **готовые HTML-страницы** в папке `public/`. Их собирает `build.py` из данных в `src/`.
- На сервере код лежит в `/opt/site/repo`.
- Сайт работает в Docker-контейнере `territoriaprazdnika-site` (nginx).
- Перед ним стоит **Traefik** из установки n8n (`/opt/beget/n8n`). Он принимает запросы на порты 80/443, сам выдаёт SSL-сертификат и направляет `territoriaprazdnika.ru` на сайт, а `n8n.neuroflow-ai.ru` — на n8n.
- Настройки сайта на сервере — в папке `deploy/` этого репозитория.
- **Настройки n8n в `/opt/beget/n8n` не трогать.**

### DNS (reg.ru)

- `A  www  → 45.147.179.203` (www перенаправляется на адрес без www)

## 3. Частые задачи

### Поправить текст, цену или добавить квест
1. Изменить `src/data/products.json` (и картинки в `src/static/img/<slug>/`).
2. `python3 build.py` (и `python3 build.py --preview` для локального просмотра).
3. Закоммитить и отправить в GitHub (`git push`).
4. Через 5 минут изменения на сайте сами.

Поля товара: `slug`, `title`, `price`, `pay_url` (ссылка на оплату), `ages`, `f_age` (`k35`, `k57`, `k810`, `k1114`, `adult`), `f_occ` (`bday`, `ny`, `gift`, `sad`), `previews` (4 картинки страниц с водяным знаком «ОБРАЗЕЦ»).

### Зайти на сервер
В PowerShell на компьютере:
```
ssh root@45.147.179.203
```
Пароль при вводе не отображается — это нормально. Веб-консоль Beget пароль часто не принимает, лучше через PowerShell.

### Сайт не обновляется
```
git -C /opt/site/repo pull
crontab -l
```
В `crontab -l` должна быть строка, которая начинается с `*/5 * * * * git -C /opt/site/repo pull`.

### Переустановить сайт (n8n не затрагивается)
```
curl -fsSL https://raw.githubusercontent.com/Svetlichok77/territoriaprazdnika-site/main/deploy/setup.sh | bash
```

### Выключить сайт (n8n продолжит работать)
```
docker compose -p site -f /opt/site/repo/deploy/docker-compose.yml down
```

### Перенести сайт на другой хостинг
Папка `public/` — это весь сайт. Её можно выложить на любой хостинг статических сайтов, а в reg.ru поменять A-записи на новый IP.

## 4. Квесты

- Готовые PDF — у владелицы (компьютер + облако). Нумерация файлов: `01.`, `02.` … `16.`
- Квесты 1–13 сделаны в ChatGPT и проверены. Их исходник — сам PDF.
- Квесты 14–16 («Протокол „Полночь“», «Кто украл ёлку?», «Тайна волшебного яйца») собраны кодом: Python пишет HTML, Chromium (Playwright) печатает его в PDF. Исходники и картинки — в закрытом репозитории `territoriaprazdnika-quests`.
- Превью для сайта: страница PDF → 110 dpi → водяной знак «ОБРАЗЕЦ» → JPG шириной 700 px.
